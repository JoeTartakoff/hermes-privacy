# Privacy Policy — Hermes AI Assistant

Hermes AI Assistant is a personal automation tool built and used solely by its 
developer (YOUJONG) for private, non-commercial use.

## Data Accessed
- Google Calendar (read-only): to generate daily/next-day schedule briefings.
- Google Drive (read/write): to read and update files for personal report 
  generation.

## Data Usage
Data accessed is used only to generate briefings and reports delivered to the 
developer via Discord. It is not shared, sold, or disclosed to any third party.

## Data Storage
Access tokens are stored locally on the developer's own machine and are not 
transmitted to any external service beyond Google's own APIs.
